## Память проекта (обязательна при работе)

В этом workspace есть поисковая память: `mem0-like\memory.md` (документы по одному факту)
+ `mem0-like\search.py` (SQLite FTS5 + векторы multilingual MiniLM-L12-v2).

Запуск поиска:

    mem0-like\.venv\Scripts\python.exe mem0-like\search.py "запрос" -k 5

Другые режимы: `--no-embed` (точный поиск без векторов), `--add "текст"` (добавить документ),
`--reindex`, `--stats`. Индекс `mem0-like\memory.db` перестраивается сам при изменении `memory.md`. Окружение после клонирования собирает `python mem0-like\init.py` (venv, пакет, модель, индекс); диагностика без правок — `python mem0-like\init.py --check`.

### Когда вызывать поиск

Перед ответом про цифры, совместимость или решения по этой сборке — CPU, плата, RAM, кулер,
короб/воздушный поток, шум, БП, корпус и крепления, fan-control, сеть, диск, троттлинг.
Не пересказывать числа по памяти: сначала поиск, потом ответ с номерами документов.

### Когда писать в память

Новое решение, подтверждённая карточка товара, результат измерения или проверка после сборки —
сразу одна строка через `--add` (или правкой `mem0-like\memory.md`). Формат: один bullet = один факт,
`##` = раздел. Точные единицы и модель сохраняются текстом, не пересказом.

## Ограничения окружения

- Windows + PowerShell; Python 3.12; node/npm и ollama отсутствуют.
- Рабочая директория: `C:\Users\USERNAME\Documents\Strata\Workspace`.
